How well does your AI understand Hindi and Hinglish?

touchstone gives any AI model a short exam in Hindi and Hinglish, checks every answer with fixed rules, and shows a clear report. Same questions and settings for every model, so results are fair.

▶ Try it free in Colab View on GitHub

No install needed in Colab. Bring your own free key (Gemini, Groq, OpenRouter) or use the practice model.

Three steps, one clear answer

Works with Gemini, Groq, OpenRouter, Hugging Face, OpenAI, Claude, Mistral, DeepSeek, xAI, Together AI, Ollama, or your own server. Your key stays on your computer.

1

Pick a model and topics

Choose a provider, paste your own key, and pick from suggested models or type any model name.

2

It answers the questions

Every model gets the exact same prompts at temperature 0. Replies are saved as they arrive, so a run can resume.

3

See the result

A score per topic, every question and answer to check, side-by-side comparison, and a leaderboard chart to share.

What it tests

Six small tasks, written for this project and reviewed by people. Scoring uses fixed rules, never another AI as judge.

Hindi readingRead a short passage, answer a question.मीना अपनी दादी के साथ बाज़ार कब जाती है?
Hinglish chatUnderstand Roman-script chat, including sarcasm."Wah, kya perfect timing hai meri!" — bus chhootne ke baad
Hindi to EnglishTranslate, scored with chrF.कृपया दरवाज़ा बंद कर दीजिए।
Hinglish instructionsFollow an instruction exactly.Teen Indian sweets ke naam batao, comma se alag karke.
Hindi mathsSolve a word problem; ६०० and 1,00,000 understood.800 रुपये की कमीज़ पर 25% छूट, कितने की पड़ेगी?
Everyday IndiaNeutral facts: food, festivals, geography.इडली बनाने में किन चीज़ों का इस्तेमाल होता है?

Built to be fair

A benchmark is only useful if people can trust it.

✓

Same test for every model. Fixed temperature, seed and prompts.

✓

Nothing hidden. Every prompt, reply, date and model id is saved.

✓

Anyone can check. touchstone reproduce reruns a saved test.

✓

No hype. Sample sizes always shown, ties shown as ties.

Run it on your computer

Python 3.10 or newer. No GPU needed; built on an 8 GB laptop.

# install, then open the web UI
python -m pip install "touchstone-llm[ui]"
python -m touchstone_llm ui
# or from the terminal
python -m touchstone_llm run --model groq/<model> --tasks all
python -m touchstone_llm leaderboard runs/*.json

Questions are still being reviewed by people, so official results are not published yet. Fluent Hindi or Hinglish speaker? Help review questions, no coding needed.
